## 创建新配置

1. 下载 `_template_.js` 和 `_venera_.js` 文件，放入同一目录
2. 将 `_template_.js` 重命名为 `your_config_name.js`
3. 根据需求编辑 `your_config_name.js` 文件
   - `_template_.js` 文件中包含详细注释以帮助配置
   - `_venera_.js` 用于 IDE 中的代码补全
